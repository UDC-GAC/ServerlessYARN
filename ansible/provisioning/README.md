# Provisioning directory

This directory contains the main code of the repository, including Ansible automation, configuration, service definitions and helper tooling.

## Structure

- `apps/`: Configuration and scripts of applications to be deployed by the platform
- `collections/`: Ansible custom collections
- `config/`: Configuration files
- `external/`: Git submodules and external dependencies.
- `playbooks/`: Ansible playbooks
- `plugins/`: Ansible custom plugins
- `scripts/`: Helper scripts
- `services/`: Additional services to deploy alongside the platform
- `tasks/`: Ansible tasks
- `templates/`: Template files, including container image definitions
- `tests/`: Tests for specific functionalities
- `tools/`: Utility libraries.
- `vars/`: Shared variables for Ansible's tasks
